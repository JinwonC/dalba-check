D'ALBA · 크리에이터 파트너십

크리에이터 계약, 이렇게 진행합니다

계약서·인보이스 서명부터 송금까지 5단계. 파일을 주고받지 않고 링크 하나로 끝냅니다.

누가 하나요?매니저 (나)크리에이터재무팀자동으로 처리
준비

계약서 만들고 링크 보내기

매니저+ 새 계약서 에서 핸들, 제품별 영상 수, 기간, 금액 입력 → 저장하고 링크 만들기 → 링크를 크리에이터에게 전달

자동

  • 계약서와 인보이스가 함께 만들어집니다
  • 조항은 크리에이터별로 수정 가능
1STEP

크리에이터 서명

크리에이터링크에서 계약서 확인 → 은행 정보 입력 → 인보이스 확인 → 이름을 타이핑해 서명
매니저할 일 없음. 알림 메일을 기다립니다

자동

  • 서명본 PDF 완성 (계약서 + 인보이스)
  • 담당 매니저 웍스 메일로 서명 알림
2STEP

회사 직인 (계약서 상신)

매니저구글 드라이브에 자동 저장 → 날인 요청
재무팀같은 드라이브 폴더에 날인본을 넣어줍니다
매니저날인본이 올라오면 회사 직인 받음

자동

  • 서명본이 팀 드라이브 폴더에 저장
  • 업무 요청 시트에 한 행 추가
계약서 상신 · 계약서 1건 날인 요청 @핸들 · 폴더 링크
3STEP

콘텐츠 수급

크리에이터영상을 올릴 때마다 서명했던 그 링크에서 영상 링크 제출
매니저영상이 모두 들어오면 콘텐츠 수급 완료

자동

  • "10개 중 3개 제출, 7개 남음" 표시
  • DM으로 받은 링크는 매니저가 대신 추가 가능
4STEP

송금 요청 (지출결의서 상신)

매니저송금 요청일, 예상 송금일, 추진 목적 및 기대효과 입력 → 송금 요청함

자동

  • 크리에이터·금액·영상 링크 자동 입력
  • 폴더 링크는 2단계 것을 그대로 사용
  • 업무 요청 시트에 한 행 추가
5STEP

송금 완료

재무팀예상 송금일에 송금
매니저송금 확인 후 송금 완료

자동

  • 예상일이 지나면 대시보드에 빨갛게 표시
  • 완료하면 "완료" 목록으로 이동

대시보드에서 "다음 할 일" 읽는 법

링크 보냄, 서명 전크리에이터
서명됨 → 날인 요청하기나
날인 요청함재무
영상 올리는 중크리에이터
영상 다 들어옴 → 수급 완료, 송금 요청나
송금 요청함재무

기억할 것

  • 로그인은 아웃리치 프로그램과 같은 아이디·비밀번호
  • 크리에이터에게 보내는 링크는 하나: 서명도, 영상 제출도 같은 링크
  • 드라이브 폴더도 하나: 날인 요청과 송금 요청이 같은 폴더
  • 대시보드 맨 위 "내 조치가 필요합니다" 숫자만 0으로 만들면 됩니다
  • 서명 후에는 계약서를 수정할 수 없습니다
