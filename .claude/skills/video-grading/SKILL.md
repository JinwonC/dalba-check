# d'Alba 크리에이터 영상 콘텐츠 평가 (GOOD / OK / BAD)

## 목적
TikTok Shop 크리에이터 영상의 **콘텐츠 자체 품질**을 평가한다.
- 크리에이터 섭외 판단(월 판매량, 언어, 페르소나, 채널 성격)은 **등급에 넣지 않는다.** 별도 칸에 적는다.
- 판매 성과(GMV, 조회수)도 등급 근거가 아니다. 조회수는 크리에이터 계정 노출력에 크게 좌우되기 때문이다.

## 입력 (영상을 직접 볼 수 없으므로 반드시 아래 형태로 받는다)
1. **프레임 컨택트시트 1장**: 0, 0.5, 1, 1.5, 2, 3초(훅 구간) + 나머지 구간 균등 10장, 각 프레임에 타임스탬프 표기
2. **대본**: 음성 인식 결과, 구간별 타임스탬프 포함 (언어 자동 감지)
3. (있으면) 영상 캡션, 제품명, 영상 길이

프레임이나 대본이 없으면 평가하지 말고 무엇이 빠졌는지 말한다. 영상이 삭제·비공개라 받을 수 없으면 `N/A`.

## 1단계: 자동 BAD (하나라도 해당하면 2단계 없이 BAD)
| 코드 | 기준 |
|---|---|
| `PRODUCT_ONLY` | 사람 얼굴이 (거의) 안 나오고 제품만 보여줌. 제품 흔들기, 박스만, **손등·손목에만 발라보기**도 포함 |
| `AI_CONTENT` | AI 생성 영상/렌더링 같은 연출, AI 음성 |
| `NO_TALK_NO_TEXT` | 말도 없고 설명 자막도 없음 (음악만). 단, 설명 자막이 있으면 통과 |

## 2단계: 핵심 5요소 (각각 YES / NO)
| # | 요소 | YES 기준 | NO 예시 |
|---|---|---|---|
| ① | **Hook** | 첫 3초 안에 고민·타깃을 짚거나 궁금증을 만든다. 예: "30대 이상이라면", "양쪽 얼굴 차이 보여요?", "이거 사지 마세요", "I wasted so much money on skincare", 결과 피부를 0초에 보여주며 놀람 | 훅 없음, 서론이 길다, "제품 3개가 와요" 같은 단순 나열, 첫 3초에 고민과 무관한 말 |
| ② | **Proof on skin** | **얼굴에 직접** 바르고, 결과가 보인다 (피부 클로즈업, 광채·탄력, 비포·애프터, 반쪽 비교) | 병만 들고 설명, 제품으로 얼굴을 가림, 손등에만 바름, 주름을 손가락으로 짚기만 함 |
| ③ | **Explanation** | 사용 순서·루틴, 핵심 성분(볼루필린, 트러플, 콜라겐 등), 텍스처, 누구에게 맞는지 중 하나 이상을 **구체적으로** 설명 | "뭔지 모르겠지만 좋다", 할인·배송 얘기뿐, 제품 이름만 나열 |
| ④ | **Authenticity** | 본인 경험이 담긴 자연스러운 리뷰. 나이·사용 기간 공개, 진짜 반응, 댓글·이전 영상 같은 사회적 증거 | 대본 읽기, 광고처럼 보임, 홍보 멘트(무료배송·서둘러)가 절반 이상, 개인 경험 없음 |
| ⑤ | **CTA** | 영상 **마지막 부분**에 구매를 유도한다. 예: "지금 할인 중이에요", "오렌지 카트 눌러보세요", "구매하세요", "지금 사세요", "link below", 마지막 화면의 장바구니·할인 자막 | 구매 유도 없이 끝남, 유도가 처음·중간에만 있고 끝에는 없음 |

CTA와 진정성은 따로 본다. 마지막의 짧은 구매 유도는 CTA YES이고 진정성을 깎지 않는다. 영상 대부분이 할인·서둘러 멘트(딜 화법)이면 CTA는 YES여도 진정성은 NO다.

**제작 품질**(별도 체크): 조명이 피부를 보기에 충분한가, 음성이 또렷한가, 화면이 심하게 흔들리지 않는가, 얼굴이 가려지지 않았는가(모자·제품 등).

## 3단계: 등급
| 등급 | 규칙 | 의미 |
|---|---|---|
| **GOOD** | 5요소 모두 YES, 그리고 제작 품질 양호 | Spark Ads·재섭외 후보 |
| **OK** | YES 2~4개, **또는** 5개 다 YES인데 제작 품질이 나쁨 | 장점이 분명함. "이것만 고치면 GOOD" 피드백 대상 |
| **BAD** | 1단계 해당, **또는** YES 1개 이하 | 사용하지 않음 |

판단이 애매하면: 훅이 약하지만 나머지가 강하면 OK가 아니라 **GOOD 가능**(타깃을 정확히 짚는 평이한 훅은 YES로 본다). 반대로 요소를 억지로 YES로 주지 않는다. 근거가 화면이나 대본에 실제로 있어야 YES다.

## 4단계: 플래그 (등급과 별개로 표시, 점수에 반영하지 않음)
- `CLAIM`: 과장·의료성 표현. 예: "Botox in a bottle", "brushed on Botox", "Boob filler", 필러·주사 대체, "살롱급 리프팅", 주름·모공 "개선" 단정
- `MISINFO`: 제품 설명 오류. 예: 2단계 패드를 "낮용·밤용"으로 설명
- `NON_EN`: 비영어 (US 기준. 섭외 판단 참고용)
- `PROFANITY`: 비속어
- `LONG`: 60초 초과이면서 첫 제품 등장이 10초 이후

## 출력 형식
영상마다 아래 JSON 한 개, 이어서 사람이 읽을 요약 2~4줄.

```json
{
  "video_id": "7691017456470592781",
  "gate": null,
  "hook": "YES", "proof_on_skin": "YES", "explanation": "YES", "authenticity": "YES", "cta": "YES",
  "production": "GOOD",
  "grade": "GOOD",
  "flags": ["CLAIM"],
  "evidence": "0초 광채 피부+놀람 훅, 40s 브러시로 얼굴에 바름, 50,000PPM 볼루필린 자막, 댓글 화면 사회적 증거",
  "feedback": "GOOD이면 왜 좋은지 / OK면 무엇을 고치면 GOOD인지 / BAD면 왜 나쁜지"
}
```
- `evidence`에는 **타임스탬프와 함께** 화면·대본에서 본 근거를 쓴다.
- OK의 `feedback`은 **구체적 행동**으로 쓴다. 예: "45~60초로 줄이고 첫 3초 안에 세트를 보여주기", "미스트를 직접 얼굴에 뿌리는 장면 추가".

## 하지 말 것
- 월 판매량·언어·페르소나를 이유로 등급을 깎지 않는다 (섭외 판단 칸에 따로).
- 캡션만 보고 판단하지 않는다. 화면과 대본의 근거로만 판단한다.
- 근거가 불확실하면 YES로 주지 말고 `evidence`에 "확인 불가"라고 쓴다.

## 프레임·대본 만들기 (Claude Code 환경)
이 저장소의 `video_grading/extract.py`(프레임 컨택트시트 + 16kHz wav)와 `video_grading/transcribe.py`(faster-whisper small, 언어 자동 감지)를 쓴다.
```bash
pip install imageio-ffmpeg pillow faster-whisper
python -I video_grading/extract.py <video.mp4> <out_dir>
python -I video_grading/transcribe.py <out_dir>     # out_dir 안의 모든 wav를 변환
```
영상 파일은 CRUVA `get_video_download_url`로 받는다 (삭제·비공개면 404 → N/A).
